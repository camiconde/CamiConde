### 🚀 Proyectos destacados

#### 📊 [Metric Mindset](https://github.com/camiconde/Proyecto-Final-Henry)

Sistema end-to-end de Machine Learning que predice la probabilidad de conversión en e-commerce.

- Modelo **LightGBM** con optimización de hiperparámetros vía **Optuna** (Búsqueda Bayesiana).
- **Precision@10%: 80%** · **Recall@10%: 51%** · ROC-AUC: 0.92 · F1-Score: 0.78
- Dashboards interactivos en **Power BI** para traducir el EDA en insights de negocio.
- API REST desplegada con latencia de inferencia < 50 ms.

#### 🏭 [FleetLogix S.A. — Big Data e Inteligencia de Negocios](https://github.com/camiconde/-Big-Data-e-Inteligencia-de-Negocios-para-FleetLogix-S.A.)

Data Warehouse y pipeline ETL para una empresa de logística (Proyecto Integrador II de Henry).

- **Data Warehouse en Snowflake** (modelo en estrella) a partir de una base transaccional de 1.6M de registros en PostgreSQL.
- **Pipeline ETL en Python (Pandas)** que procesa la carga completa en 114 segundos, depurando 1.279.748 transacciones.
- Recomendaciones estratégicas de negocio: segmentación de clientes y optimización de costos operativos.
